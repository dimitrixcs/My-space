MY ESPACE · ORBITAL EDITION

Seu espaço está quase pronto.

O aplicativo foi aberto como um arquivo local. Como ele usa módulos JavaScript e dependências, o navegador não consegue carregá-lo corretamente com um duplo clique no index.html.

01
Windows 10/11

Feche esta página e dê dois cliques em INICIAR_MY_ESPACE_WINDOWS.bat.

02
macOS ou Linux

Abra o Terminal na pasta do projeto e execute ./INICIAR_MY_ESPACE_MAC_LINUX.sh. Se necessário, use primeiro chmod +x INICIAR_MY_ESPACE_MAC_LINUX.sh.

03
Prefere não instalar nada?

Publique o repositório no GitHub Pages e abra o endereço do site no navegador.

Os scripts iniciam o servidor local e abrem o My espace no navegador. Na primeira execução, precisam de internet para instalar as dependências do projeto.
